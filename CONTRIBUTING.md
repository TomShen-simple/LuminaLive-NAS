# Contributing

1. Fork the repository and create a focused branch.
2. Do not commit private playlist URLs, cookies, tokens, NAS paths, or personal domains.
3. Add or update tests for behavior changes.
4. Run `python -m unittest discover -s tests -v` and `docker compose config --quiet`.
5. Explain NAS model, CPU architecture, OS version, and Docker/Compose version in compatibility reports.

Source-list changes must use publicly documented indexes. Do not submit DRM bypasses, account cookies, or paid/private streams.
